# 微光

> *世界很小，但真相很大。*

## 世界

在无垠的宇宙中，有一个微小的球壳。

直径一百二十七米，周长不足四百米。表面覆盖着一座垂直的城，数千人栖居其间，代代相传。壳内有两颗人造光源沿固定轨道运行，提供十二小时的白昼与十二小时的黑夜。没有人在意光的来源，正如没有人过问壳外的世界——**圣典上说，外面是惩罚之地。**

这座壳叫作微界。

没有人知道它在宇宙中的位置。没有人知道它已经漂流了多久。更没有人知道，它的动力正在衰竭，它的外壳正在开裂，它的光正在熄灭。

而壳外，有什么东西正注视着它。

## 主题

这部小说探讨的是**微小之物的分量**。

- 一个直径百米的世界，能装下多少谎言？
- 一段不足千年的文明史，能掩盖多少真相？
- 一个人的一生，只是光的千万分之一个闪烁。但倘若他把每一次闪烁都记下来，那些记录会不会比光更长久？

这是关于**记录对抗遗忘**、**勇气对抗恐惧**、**渺小个体对抗宏大体制**的故事。

## 构架

全书为多幕结构，以微界的物理衰竭和权力体系的层层崩塌为两条交织主线。从日常记录的细微裂隙，到禁区的直面真相，再到出逃后的流亡与反抗，最终指向一个终极问题：

**当壳裂开的时候，里面的人敢不敢走出去？**
