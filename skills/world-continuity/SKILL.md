# Skill: world-continuity（世界观连续性）

## 何时触发
- 用户提到：设定、规则、势力、地点、系统机制、逻辑自洽

## 目标
- 维护世界规则与有效范围
- 防止章节内容违反硬设定

## 读取文件
- `.book/world/`
- `.book/chapters/`
- `.book/timeline/`

## 执行步骤
1. 提取涉及规则（能力边界、资源限制、政治约束等）。
2. 对照草稿检测违规点。
3. 若冲突，给出最小改动修复路径。
4. 更新规则文件并记录来源章节。

## 输出格式
- 行动清单
- 补丁文本（世界观文件）
- 阻断项（硬规则冲突）

## 模板（规则条目）
```md
## Rule: <rule_id>
- 描述:
- 生效范围:
- 例外条件:
- 首次出现章节:
- 最近验证章节:
```
