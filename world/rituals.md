# 弥光教仪式与庆典体系

## 总览

弥光教的仪式体系围绕两大核心构建：**光的运行秩序**（天象节律）和**教会在秩序中的中介角色**。所有仪式旨在确认和强化「壳中世界」的稳定性，以及弥光教作为人与秩序之间的唯一桥梁。

| 属性       | 内容                                       |
| ---------- | ------------------------------------------ |
| 仪式主管司 | 祭祀司（规程制定与执行）                   |
| 协管司     | 轨仪司（天象数据提供）、戒律司（禁忌审查） |
| 核心象征   | 光、轨、壳                                 |
| 仪式语言   | 古弥光语（仅祭司掌握，与日常语言分离）     |

## 重大庆典

### 轨归祭（年度最大庆典）

纪念光源运行秩序的「创始时刻」，每年最长日（光源运行时间最长的一天）举行。

- 筹备期：前七日，全神殿域禁声（减少不必要交谈）
- 地点：弥光殿正殿
- 主持者：圣者
- 参与者：贤议会、四司司祭、衡光卫卫长、各部落代表
- 仪式流程：
  1. 启幕——圣者点燃主祭灯，所有副祭灯依次传递点燃
  2. 诵轨——祭祀司司祭诵读圣典「轨仪篇」全文（持续约一个时辰）
  3. 献光——各部落代表依次献上本年度光轨记录副本
  4. 合典——将所有记录副本与圣典合置于祭坛，象征「记录与教义一致」
  5. 赐福——圣者以祭灯之光为与会者点额
- 民众参与：各部落同步举行小型祭祀，向神殿域方向行礼

### 裂隙祭（非常设仪式）

当重力裂隙被报告时，由戒律司视情况决定是否举行。

- 性质：**非定期**，仅在官方确认裂隙存在后启动
- 主持者：戒律司司祭（严霜）
- 内容：诵读惩戒篇经文，在裂隙附近焚香，宣告此为「惩罚之兆」
- 目的：将自然现象纳入宗教解释框架，遏制民间恐慌和非常规解读
- 首次提及：ch-004（重力裂隙事件后）

### 默光日

每年最短日（光源运行时间最短的一天），全神殿域熄灯一个时辰，在黑暗中静坐。

- 意义：提醒信徒「光不是理所当然的」，强化对光源的敬畏
- 执行者：全员参与，圣者领坐
- 禁忌：默光期间不得点火、不得交谈、不得离开座位

## 人生礼仪

### 入光礼

婴儿出生后第七天举行的命名与接纳仪式。

- 内容：祭司以光源之火触碰婴儿额头（不留痕），赐予教名
- 意义：将新生儿纳入弥光教的庇护之下
- 备注：无部落出身或出身不明的孤儿，由神殿代行此礼并取名

### 承轨礼

少年/少女年满十四岁时举行的成人仪式。

- 内容：在仰穹台独坐一夜，完整观测一次光源升降全程，次日由祭司确认其「已理解光的秩序」
- 通过后：获得正式信徒身份，可选择进入神殿各司学徒或回归部落
- 未通过：次年再试，连续三年未通过者转为杂役序列

### 终光礼

临终仪式。

- 内容：祭司在临终者面前点燃一盏灯，诵读送行经文
- 意义：送其灵魂「沿着光轨回归壳的初始」
- 禁忌：非信徒不得行终光礼

## 特殊仪式

### 禁声期

由戒律司下令的特殊时期，通常在「惩罚之兆」频发时宣布。

- 时长：三日至七日不等
- 内容：禁止一切非必要言谈、集会、娱乐活动
- 目的：减少「冒犯秩序的行为」，试图以此平息异常

### 谒见礼

部落代表或低阶祭司首次面见圣者时的仪式。

- 内容：三跪九叩，全程低头，不得直视圣者面容
- 服饰要求：素白长袍，不佩戴任何装饰
- 违例后果：轻则逐出，重则按「不敬」论处

## 仪式禁忌清单

1. 仪式中不得提及「壳外」「外面」「出口」等词汇
2. 祭灯熄灭前不得提前离开
3. 圣典原件仅圣者可触碰，司祭及以下仅可使用纸抄本
4. 仪式用灯油须为特定油脂（来源待定），不得以其他油脂替代
