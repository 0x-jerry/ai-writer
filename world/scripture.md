# 圣典 — 弥光教根本经典

## 总览

圣典是弥光教一切教义、仪式、律法的根本来源。传说其内容源自第一代圣者在壳中定居后，由光源「启示」而记录——

但这一说法从未被证实。历代记录者发现，圣典的语言体系和文字风格存在断层：部分篇章粗糙直白，部分精密晦涩，不像出自同一时代甚至同一群体之手。

| 属性 | 内容 |
|------|------|
| 全称 | 弥光圣典 |
| 材质 | 金属薄板（内层）+ 织物裱褙（外层）；卷七成分特殊，与其他六卷不同 |
| 册数 | 七卷 |
| 存放地 | 神殿域·弥光殿密龛 |
| 抄本存放 | 典藏司·经阁 |
| 语种 | 古弥光语（日常已不通用，仅祭司研习） |

## 七卷结构

### 卷一·光启

开篇卷。描述世界的起源——「壳」的闭合、光的首次亮起、秩序的确立。

- 核心句：「光遍满壳中，壳即世界，世界即壳。」

### 卷二·轨仪

记载光源的运行法则——轨道参数、升降时刻、亮度判定标准。

- 功能：轨仪司的作业手册，也是所有记录者必须背熟的内容

### 卷三·诫命

戒律清单。规定信徒「不可做」之事，按严重程度分级。

- 最高级（触碰即死罪）：寻找出口、质疑光的永恒性、毁坏圣典
- 中级：在仪式中渎职、传播异端解释
- 低级：日常言行失检

### 卷四·祭仪

所有仪式的规程——从轨归祭到裂隙祭，从入光礼到终光礼。

- 特点：极尽繁琐。对每一步的动作、方位、用物都有精确规定

### 卷五·史传

从第一代圣者到当代的历代记录。但不是客观历史——每一代圣者的事迹都经过了筛选和润色。

- 缺失：中间多代圣者的记录存在明显断层（卷五比其他卷薄得多）

### 卷六·预言

据称是「尚未应验」的内容。篇幅最短，文字最晦涩，多义性最强。

- 使用限制：只有圣者和贤议会可查阅全本；其余人仅可接触祭祀司摘录的节选

### 卷七·留白

第七卷是空的。金属板面干净如镜，一个字都没有。

- 材质特殊：此卷金属板的成分与其他六卷不同——无人知其来源，也无人能复制。它不吃錾刻、不吸墨迹，任何外力都无法在其表面留下痕迹
- 文字显现：每当有真正的预言要降下时，文字会自行浮现于板面，如从金属内部渗出。无须人书写，也无从伪造
- 消退：预言应验或失效后，文字逐渐变淡直至完全消失，板面恢复如镜
- 现状：上一次板面有内容已是数代之前，如今无人记得那些预言写了什么。空白不是因为被抹去，而是因为没有新的「真预言」出现

## 物理形式

- 卷一至卷六：每一页为一整块金属薄板，双面錾刻文字
- 卷七：金属板成分为特殊材质，不吃錾刻不吸墨迹，表面始终如镜
- 七卷叠放于密龛中，单卷重量略大于同尺寸书册，一人可抱取
- 抄本为纸册（手工抄录），仅录文字不摹刻花纹
- 保养：每季由典藏司用特定油料擦拭织物裱褙及抄本；金属板面本身不需保养（特殊材质不氧化）
- 其他材质（骨、木、石）的抄本被认定为无效——只有金属板原件和纸抄本具有权威性

## 传承规则

1. 圣典原件仅圣者可触碰；司祭及以下仅可使用纸抄本
2. 抄录须在典藏司监督下进行，每抄完一卷由司祭核验用印
3. 抄本破损后须当众焚烧，不可随意丢弃
4. 口传内容不得在圣典原文旁标注——口传与成文必须物理分离
5. 遗失抄本者降级，故意毁坏者逐出神殿
