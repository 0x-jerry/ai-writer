# 文风指南（Style Guide）

> 本文档是小说写作的风格参考，而非硬性规范。写得顺畅时优先相信直觉；写卡壳时回来找方向。每一条规则都有例外，关键在于知道何时打破它。

## 整体定位

以 **感官沉浸（⑤）** 为主体，融入 **寓言体（③）** 的距离感。

### 两种模式的选择

| 模式 | 适用场景 | 最佳效果 |
|------|----------|----------|
| 感官沉浸 | 日常叙事、初次进入新空间、关键物件的发现、独处时刻 | 让读者"住进"主角的身体 |
| 寓言体 | 章节收束、重大转折后、主角做出不可逆选择的瞬间 | 让读者退后一步，感受命运的轮廓 |

写作时先判断当前段落属于哪种模式，然后调用对应的工具箱。大多数篇幅用感官沉浸；寓言体只在关键位置使用，每章 1–3 处即可。

- 日常叙事：紧贴主角的五感——风的气味、石栏的温度、光落在皮肤上的触感。让读者通过感官进入微界。
- 关键节点：叙事短暂拉开距离，用寓言体的语气给出重量感观察或预言式的句子。用来收束段落、标记转折、暗示宿命。

### 感官沉浸的具体技法

**五感轮替**：避免连续使用同一感官。视觉一段后换触觉，触觉后换嗅觉。如下雨场景：先写雨丝砸在皮肤上的凉（触觉），再写空气中泥土翻涌的腥甜（嗅觉），最后写远处屋檐水帘模糊了灯火（视觉）。

**微观感知链条**：不写"天气很冷"，写"他呼出的气在面前凝成一团白雾，白雾散了，指尖还在发麻"。

**身体先行**：让主角的身体比意识更早感知环境变化——耳廓先捕捉到那声异响，瞳孔先收紧，肩胛骨先绷住。意识的判断随后到。

**环境与人物的交互**：感官描写不是装饰，而是主角与世界的对话。风推着他走，石板绊他的脚，暗处有什么在注视他——让环境始终是活的。

### 寓言体的使用节律

寓言体句子出现的典型位置：

- **段落收束处**：一段沉浸描写之后，用一句话收住，让它悬在半空。
- **场景切换前**：在空间或时间跳转的前一句，给出预言式的断语。
- **主角做出选择之后**：行为落定，叙事退后一步，留下一句重量感观察。
- **章节末句**：作为章节收束，让读者合上这一章时脑中仍有回响。

寓言体的语言特征：

- 主语常为事物而非人物（"风不会记得自己推过哪片叶子"）
- 用泛化的时间词（"迟早""终有一天""很久以后主角才会明白"）
- 动词用存在式而非行动式（"在""悬""沉""浮"）
- 拒绝解释，只给出画面或判断，不解释因果

## 叙述约束

- 叙事视角：第三人称有限视角，紧贴主角的感知与内心
- 时态：以现在时为主，随叙事需要可插入回顾性过去时
- 节奏：沉浸段偏慢（五感铺陈 + 短句收束交替）；推进段换短镜头切换保持张力

### 视角纪律

- **所见即所感**：主角不知道的事，叙述者不说。主角没注意的细节，不在描写中出现。
- **内心出入规则**：允许进入主角的内心——他的判断、记忆、情绪——但必须是"他正在想"的自然流露，而非事后总结。不允许进入其他角色的内心。
- **信息梯度**：主角和读者知道的一样多。解开谜团时，主角先发现端倪，读者随他一步步接近真相。

### 节奏控制细则

**慢段落（沉浸段）**：
- 节奏型：长句铺感官 → 长句再铺 → 短句收束 → 空行 → 下一单元
- 营造呼吸感：一段沉浸描写后，用一个短句或寓言句收束，再换行给读者停顿空间
- 沉浸段连续铺陈超过 400–500 字后，读者容易感官疲劳，此时可用短句收束、环境空镜或对话切入来重置注意力

**快段落（推进段）**：
- 节奏型：动作短句 → 反应短句 → 环境闪回 → 再动作
- 单段不宜超过 150 字，频繁换行保持呼吸
- 感官描写精简到最少：只保留一两个关键感官（通常触觉或听觉）
- 对话推进时，适当穿插主角的微反应（喉结滚动、指尖收紧、视线移动）

**变速节点**：在快慢段落切换处，用一个寓言体短句作为过渡阀门。

### 段落结构规范

- **段落起点**：建议以感官/空间/身体状态开局（"石阶上长了一层薄霜""主角的右手腕开始发酸"）
- **段落中部**：行动 + 感知交替推进
- **段落终点**：建议用短句收束或寓言体断语制造落地感（"然后光灭了""有些门一旦推开就关不上"）。不是每段必须有，但一章中超过一半的段落没有落地感，读起来会飘。
- **段落长度**：主叙事段 100–300 字为宜。短段落（≤50 字）用于强调、节奏变化。偶尔的长段落（500+ 字）可以制造沉浸感或压迫感——关键是你清楚为什么要拉长。

## 语言约束

- 偏好词汇：感官导向（风、光、温度、气味、触感）；简洁动词（走、落、翻、压、停）
- 禁用词汇：滥用成语（尤其四字熟语串）；浮夸形容词（"致命的""震撼的"）；现代口语突兀感（"好吧""其实"）
- 句式倾向：以短句为主，偶有长句铺陈感官。段落收束用短句或寓言式断语。

### 动词使用规范

- **具体动词优先**：不写"他走路"，写"他踩过""他迈过""他绕过"。"走路"是概念，"踩"是动作。
- **连动尽量不缀导引词**："他穿过巷子，翻过墙"优于"他先穿过了巷子，然后翻过了墙"。动作本身的顺序就是逻辑，不需要"然后""接着""之后"来导航。但当节奏需要呼吸时，偶尔用一次"然后"反而可以制造停顿——区别在于有意为之还是顺手写的。
- **动作密度**：快段每句含 1–2 个核心动词。慢段允许动词稀疏，让环境词（风、光、影）做主语。
- **状态动词倾向**："在""是""有"尽量少用作描写句的主干。不写"墙上有一道裂缝"，尝试写"一道裂缝从墙角爬上屋檐"。不写"他在暗处"，尝试写"暗处吞没了他"。但这个规则不适用于对话引导句（"他站在门口"完全没问题）。

### 形容词使用规范

- **一个名词配一个修饰**：建议至多一个形容词修饰一个名词。"厚重而冰冷的大理石栏杆"可拆为"冰冷的大理石栏杆"或分两句写。刻意堆叠形容词偶尔可以制造密度感，但如果每页都出现，会稀释每个形容词的力度。
- **感官形容词优先**：冷、热、粗糙、光滑、腥、甜、闷、刺耳——来自感官的形容词优先于情感形容词（悲伤、愤怒、恐惧）。
- **情感命名的节制使用**：默认用身体反应和环境映射来呈现情感（"主角的后背贴紧了墙壁""有什么在胃里翻了一下"）。但在以下情况可以直接命名情感，反而更有力度：（1）极简短句收束——"他怕。"（2）情感复杂到身体无法简单呈现时——"那是一种混杂着感激与屈辱的复杂情绪。"（3）长篇感官写累了的章节中段，偶尔直说一次，作为节奏喘息。

### 用词倾向

以下倾向代表本文风的审美方向，不是绝对禁令。修改稿件时，如果看到表中左列的内容，问自己：换成右列会不会更好？

| 类别 | 避免 | 倾向 |
|------|------|------|
| 成语串 | "小心翼翼""漫不经心"连续使用 | 拆解为具体动作 |
| 浮夸形容词 | "致命的""震撼的""无与伦比的" | 用具体感官细节代替程度修饰 |
| 现代口语 | "好吧""其实""反正""老实说""卧槽" | 删除或用叙事替代 |
| 网络用语 | 一切网络流行语、缩写 | — |
| 程度副词泛滥 | "非常""极其""特别""十分" | 用更精确的感官词代替 |
| 抽象名词堆砌 | "命运""宿命""永恒""绝望"直接命名 | 用具体意象承载抽象含义 |
| 感叹号滥用 | 对话外使用感叹号 | 用短句力度代替感叹号 |

### 句式多样性控制

短句是本文风的主力，但长篇需要句长变化来维持阅读节奏。以下为建议比例，章节类型不同可灵活浮动：

- **短句（≤15 字）**：日常叙事中约占一半，动作场景中可占八成。用于动作、对话间穿插、段落收束。
- **中句（15–30 字）**：用于感官铺陈、环境描写、内心独白。
- **长句（>30 字）**：用于连续的感官流或思绪流。不需刻意回避，关键看这段是否需要"一口气读完"的推进感。
- **句末手法**：关键句收束时，偶尔使用单字词结尾制造停顿感——"然后光灭了。" "他停。" "不。"

实用的自检方式：读完一段，如果喘不过气，说明短句太多需要拉开；如果注意力漂移，说明长句太久需要打断。

### 段落间的留白

- 场景切换：空一行 + 首句立即建立新空间/新时间
- 时间跳跃：空一行 + 时间锚点句（"三天后""那年入冬之前"）
- 情感强转：空一行即可（不解释过渡），让留白承载情绪变化的重量

## 人物对白约束

### 对话总则

- **对话叙事化**：对话不依赖引号内的内容独立传达信息。对话前后必须有主角的感官反应、动作细节、或环境描写做锚点。读者理解的永远比角色说出的更多。
- **短对话倾向**：单句对白一般不超过 25 字。当某个角色确实需要进行长段独白（>50 字）时，拆分为多段，中间穿插主角的观察或环境反应，让独白不变成一堵文字墙。
- **潜台词优先**：角色说出的话和真正想表达的意思之间存在缝隙。不解释这个缝隙，让读者自己感知。

### 角色差异化框架

- **语速差异**：某角色句长稳定（稳重型），某角色句长跳跃（冲动型），某角色多用问句（试探型）。
- **词汇选择差异**：某角色多引用典籍/古语（学究型），某角色只用生活词汇（朴素型），某角色习惯冷嘲或反语（距离型）。
- **对主角的称呼差异**：不同角色以不同方式称呼主角（全名、略称、职位、外号），同一角色称呼不变。
- **沉默的角色**：至少有一两个重要角色话极少，他们的沉默本身构成一种语言，主角（和读者）需要解读沉默。

### 对话与叙事的配比

- **对白占比**：日常叙事章对白（含引导句）占比约 15–25%；冲突章和高潮章对白占比可以更高（30–40%），因为对话本身就是推进力。不必机械计算字数，写完通读一遍，如果连续两页全是叙事没有对话，或连续两页全是对话没有叙事，就可能需要调整。
- **对话引导句**：对话句前建议有引导——可以是动作（"他放下杯子"）、感官（"风声从窗缝挤进来"）、或状态（"主角没有回头"）。连续纯对白（"他说……""她说……"）不超过三四轮为佳，但密集争吵或快速交换信息的场景可以更密集。判断标准：读者是否还清楚谁在说话、角色此刻在做什么。

### 对白中的注意事项

- "呢、吧、嘛、啦"等口语后缀容易让对白轻飘。一个角色在同一个场景中至多用一两次，多了就容易滑向网文腔。但如果某个角色的人设就是轻浮型，可以适当放宽。
- 对白中避免直接交代世界观设定（"如你所知，我们这个世界……"）——这种写法会让读者意识到作者在借角色说话。
- 尽量避免对白中直接表达角色情感（"我好害怕""我很生气"）——情感从对白内容、用词选择、和叙事中自然溢出，比直接说出更有力。

## 情感与氛围

### 情感呈现原则

- **默认用身体呈现情感**：恐惧、悲伤、愤怒、喜悦——这些词在叙述中尽量少出现。让身体反应、环境映射、行动选择来呈现。但在以下情况直接说出情感词反而更有力：（1）单字收束——"他怕。"（2）累积压抑后的释放——"愤怒终于涌了上来。"（3）大段感官描写之后，偶尔直说一次作为节奏重置。
- **环境即情感**：主角的情绪状态映射到环境描写中。他恐惧时，环境中的光影变得诡谲；他坚定时，环境变得安静清晰。不是环境变了，而是主角的感知变了。
- **身体锚点**：每种情绪配一个固定的身体反应锚点（如紧张时喉结滚动、愤怒时虎口收紧），保持全书一致。

### 氛围管控

- **微界基调**：破碎感中隐含秩序，渺小中隐含庄严。日常场景保留一丝不安；激烈场景中保留一丝克制。
- **光线策略**：用光线变化标记情绪转折——场景由明转暗意味着什么，由暗转明又意味着什么。全书保持光线隐喻的一致性。
- **天气即语调**：晴天不一定是好事，雨天不一定是坏事。但某种天气在主角的感知中固定对应某种情绪走向，形成条件反射式的阅读期待。

## 自检清单（每章写完后通读一遍）

以下是通读时的关注点，不是打分表。有几项没做到不代表写得差——有些场景需要打破规则。这个清单帮你意识到自己在打破什么，以及为什么。

- [ ] 有没有连续四五百字读下来"看不见画面"的段落？如果有，加一两个感官细节。
- [ ] 情感词——"恐惧""悲伤""愤怒"等——出现了几次？每次出现是有意为之还是随手写的？
- [ ] 有没有连续使用两个以上成语的句子？有没有浮夸形容词或现代口语溜进来？
- [ ] 一段的结尾有没有"落地感"？如果某段结尾让你觉得飘在半空，考虑加一个短句收束。
- [ ] 对白部分——能分清谁在说话吗？说话时角色在做什么？读者有没有超过一页只看到对话引号？
- [ ] 快段够不够快？慢段有没有让人沉浸的空间？两者之间的切换是否突兀？
- [ ] "然后""接着""之后"等导引词去掉后，句子是否更干净？
- [ ] 章节末句重读一遍——它的余韵是什么？读者关上这一章后脑中会留下什么？
- [ ] 不同角色的说话方式是否可区分？有没有某个角色说了不符合性格的话？
- [ ] 视角有没有意外滑入其他角色的内心？

## 速查：本文风的底线

以下几条偏离后，本文风的核心辨识度会明显改变。如果不是有意做风格实验，建议守住：

- 不解释隐喻——意象自己说话
- 不替读者做情感判断——叙述给出证据，让读者自己得出结论
- 不让叙述者比主角知道得更多——视角纪律是沉浸感的前提
- 不让对白成为信息说明书——设定信息从对话中自然渗透，而非角色对着读者念
- 动作之间不缀"然后""接着""之后"——动作本身的顺序就是逻辑
- 尽量不用"是""有""在"作描写句的主干动词——让更有力的动词或意象代替它们
- 情感命名慎用——默认给出证据，特殊位置允许直接说出
