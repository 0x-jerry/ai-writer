# Skill: character-weaver（角色关系与状态）

## 何时触发
- 用户提到：人物关系、人设、角色成长、角色当前状态、对白一致性

## 目标
- 维护角色档案与关系网
- 给当前章节返回角色上下文约束

## 读取文件
- `characters/`
- `relationships/`
- `timeline/`
- `outline/chapters/`

## 执行步骤
1. 汇总角色当前状态（目标、秘密、冲突、最近事件）。
2. 读取关系边（类型、方向、强度、当前关系状态）。
3. 校验章节草稿是否违背角色阶段状态。
4. 产出角色上下文卡与建议修正。

## 输出格式
- 行动清单
- 补丁文本（角色文件、关系文件）
- 阻断项（角色行为突变、关系反转无铺垫）

## 模板（角色卡）
```md
# Character: <name>

- 核心动机:
- 当前阶段:
- 公开信息:
- 隐藏信息:
- 不可违背设定:
- 最近三次关键事件:
```
